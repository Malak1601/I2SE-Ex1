## Reproduce the small demonstration

The repository includes `data/demo_small.nrrd` and `data/demo_small.csv`:

```bash
python Ex0.py data/demo_small.nrrd data/demo_small.csv results/demo_small.mp4
```

This generates a **two-frame** video locally. To inspect its first frame:

```bash
python -c "import imageio.v2 as i; i.imwrite('results/demo_check.png', i.get_reader('results/demo_small.mp4').get_data(0))"
```

The generated `demo_small.mp4` and `demo_check.png` are not required to be present in the Git repository; their inputs and reproduction commands are provided.

## Measured performance and testing

- **Projection benchmark:** 710.91 projection FPS on a synthetic `500 × 500 × 500` `uint8` volume, ten timed projections after warm-up (`0.00141 s` per projection).
- **Automated tests:** 52 passed in 6.70 seconds in the latest recorded local run.

The benchmark excludes NRRD loading, MP4 encoding, and initial JIT compilation. See [Experiment](../docs/EXPERIMENT.md), [Testing](../docs/TESTING.md), and the [README](../README.md) for methodology and limitations.
